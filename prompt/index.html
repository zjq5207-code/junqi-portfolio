01 / SCRIPT SPLITTER SKILL

剧本拆分
不是机械切段

先读懂剧情功能，再按时间、动作与镜头逻辑拆解。
每段都保留完整的因果链与可执行交付结构。

DURATION ENGINE 20 SEC

单段生成上限

  • 中文台词≈ 4 字 / 秒
  • 情绪台词≈ 3.5 字 / 秒
  • 英文台词≈ 3 词 / 秒
  • 机位节点2–10 / 段
OUTPUT SCHEMA固定交付协议
  1. 01本镜简述100–200 字，先说清叙事功能
  2. 02时长与台词核算超时自动拆段
  3. 03重要备注最高优先级红线
  4. 04人物与素材引用资产只在引用区出现
  5. 05场景 / 光影每镜明确建立或延续
  6. 06姿态 / 站位 / 质感空间与物理连续
  7. 07提示词正文按时间码编译镜头执行
  8. 08交付校验每段 ≤ 3000 中文字符

02 / JIMENG PROTOCOL

即梦提示词
生成规则

把提示词分成有优先级的模块。先锁定不可违反的规则，
再组织人物、空间、影像与声音，最后写入时间码。

P0
最高优先

不可违反的交付红线

无 BGM、无画面文字、关系轴锁定、物理真实、结尾方式明确。

P1
WORLD

人物 + 素材 + 场景

明确出场人物、资产引用、空间结构，以及本镜“建立 / 延续”。

P2
IMAGE

光影 + 站位 + 材质

写清主辅光、冷暖、动作位置、受力关系、反假与负向词。

P3
CAMERA

机位 + 运镜 + 构图

以机位单元和时间码描述焦段、角度、运动、切换与构图意图。

P4
SOUND

音效 + 环境声 + 配音

声音跟随动作节点进入；台词只通过配音呈现，不污染画面。

03 / CAMERA ROUTER

先选择镜头逻辑，
再生成运镜

镜头不是随机修饰词。系统根据连续动作、信息密度与情绪转折，
在两种明确的导演策略之间做路由。

USE WHEN

动作与物理连续性优先

同一摄影机身份、同一条物理路径，机位与主体共享惯性框架。景别变化必须来自真实位移，不允许切换、重置或越轴。

  1. 01单一摄影机身份
  2. 02首尾运镜连续相接
  3. 03景别随距离自然变化
  4. 04动作因果不中断
USE WHEN

信息、对白与情绪转折优先

每次切换都是独立机位单元，必须标注时间码、机位高低、角度、景别、运动方式与转场逻辑。固定镜头与运动镜头约 2:1。

  1. 01每个切点独立定义
  2. 02对白使用正反打 / 过肩
  3. 03动作匹配保持连续
  4. 04关系轴始终同侧
